================================================================================
🚀 GETTING STARTED
================================================================================

1. Check deployment status:

   kubectl get pods -n {{ $namespace }} -l app.kubernetes.io/instance={{ $releaseName }}

2. View API server logs:

   kubectl logs -n {{ $namespace }} -l app.kubernetes.io/component=server --tail=50 -f

3. Check CronJob schedules:

   kubectl get cronjobs -n {{ $namespace }}

4. View recent job executions:

   kubectl get jobs -n {{ $namespace }}

{{- if .Values.server.enabled }}

5. Access the API server:

   {{- if .Values.ingress.enabled }}
   {{- range .Values.ingress.hosts }}
   
   External URL: https://{{ .host }}
   {{- end }}
   {{- else }}

   Port-forward to access locally:
   kubectl port-forward -n {{ $namespace }} svc/{{ include "stalkerr.fullname" . }} 8080:80
   
   Then visit: http://localhost:8080
   {{- end }}

6. Check API health:

   kubectl exec -n {{ $namespace }} deployment/{{ include "stalkerr.fullname" . }} -- \
     curl -s http://localhost:8080/health
{{- end }}
